# Jasy Kultural

Directorio digital de artistas y agenda cultural del Paraguay.

## 📌 Descripción

Este proyecto consiste en una landing page desarrollada como trabajo práctico final, cuyo objetivo es reunir en un mismo espacio:

- Directorio de artistas
- Agenda de eventos y lanzamientos
- Canal de difusión cultural

La propuesta busca funcionar como un catálogo digital de la escena artística local.

## 🧩 Secciones

- Header con navegación
- Hero / presentación
- Descripción del proyecto
- Cita conceptual
- Grilla de artistas
- Agenda cultural
- Formulario de contacto
- Footer

## 🛠 Tecnologías

- HTML5
- CSS3
- Diseño responsive (mobile first)
- Grid y Flexbox

## 🎨 Diseño

El diseño está inspirado en sitios de instituciones culturales como museos contemporáneos:

- Estética minimalista
- Uso de blanco, negro y colores primarios
- Enfoque editorial y tipográfico
- Grillas estructuradas

## 📱 Responsive

El sitio se adapta a:
- Mobile
- Tablet
- Desktop
